## P0 — 阻塞/误导

### #01 确认题目页把内部报错原文拍给老师
现象：识别批次失败时展示 `Client error '400 Bad Request' for url 'http://reference-algorithm:3417/api/layout' For more information check: https://developer.mozilla.org/...`
根因：识别批次失败原因直接渲染 httpx 异常文本（含内网地址和 MDN 链接）。
影响：违反「技术参数不出现在老师界面」的第一设计原则；老师完全看不懂。
建议：后端把批次 error_message 映射成人话（「版面分析服务暂时不可用，请重试」），调试细节收进「批次详情（调试）」折叠区。

## P1 — 功能/数据正确性

### #02 批卷工作台第 4 题裁切图只有题干、没有学生作答区
现象：识别结果「[无法辨认]」，AI 建议说明「题区原图仅显示印刷题干，学生作答区域被截断」。
根因：该题的题块区域框选过小/位置偏移，裁切没覆盖作答区。
影响：这题全班都只能人工批，AI 判分为 0 并需复核——这正是内测报告里「9 题未作答系统也没批改」类问题的上游原因之一。
建议：区域校正流程加「裁切完整性自检」（作答区高度过小时提示重新框选）；短期在批卷页给这种题标「区域不完整，请人工批」。

### #03 成绩详情/改卷报告里错题的答题裁切图空白
现象：错题回顾卡片里应显示学生作答图的位置是一块空白深色矩形。
根因：裁切图加载失败时无占位/无错误提示（也可能是 #02 同源：区域没切出图）。
建议：图片加载失败显示「答题图暂不可用」占位；并与 #02 一起修。

### #04 演示考试满分 59 分
现象：班级分析显示「平均分 19.9 / 满分 59」，内测卷实际应为 100 分制。
根因：该考试的题目分值设置不全（部分题未设满分或未纳入统计）。
建议：考试设置里加「满分合计」校验提示（题目分值合计 ≠ 试卷满分时提醒）。

## P2 — 体验细节

### #05 知识图谱页顶栏标题显示「成绩报告」
根因：`_layout.tsx` 的 pageTitle 映射漏了 /my/knowledge（default 分支落到「成绩报告」）。

### #06 手机端错题本 tab「考前清单」被截断成「考前清」
建议：tab 文字超出时缩小字号或允许横向滚动。

### #07 得分分布条形图超出轨道压住右侧计数标签
现象：「零分题 67%」的粉色条顶到「14 题·67%」文字上。
建议：条形宽度按轨道计算，label 移出轨道右侧预留固定列。
