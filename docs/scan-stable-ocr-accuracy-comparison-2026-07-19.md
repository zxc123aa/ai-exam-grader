# 稳定摆正算法 OCR 准确率对比报告（2026-07-19）

## 1. 结论摘要

本次测试对象是当前后端 `scan_stable_v1` 稳定摆正算法，输入为当前物理样本的 5 张原始图片。

结论：首次测试没有通过验收；随后已修复 sidecar 的 JSON 容错、跨页续题合并和 overlap 贴边伪题块过滤，复测后结构层面已达到当前样本 Q1–Q18 连续无重复。

原因不是单纯“透视摆正失败”，而是后续 Gemini 版面/题块检测没有稳定覆盖全卷：

- 几何预处理：5 张输入正确输出 8 页，页数通过。
- 摆正残余倾斜：约 `0° ~ -1.96°`，仍有轻微倾斜。
- 首次识别结果：19 条结果，表面题号覆盖 Q1–Q18，但 Q3 重复，第 7 页真实 Q16/Q17 因 JSON 解析失败被丢弃。
- 修复后识别结果：18 条结果，Q1–Q18 连续，无重复、无缺题。
- 当前样本真实字符准确率：不能给出有效数值，因为仓库现有 `data/golden/physics-2021-2022-b/printed_questions_gold.json` 不是这套卷子的 gold。
- 修复后平均模型置信度：0.9017，但这不是准确率。

所以当前可以说“题号结构召回已修到 18/18”，但仍不能宣称“文字准确率 95% 以上”，因为还缺当前样本的人工 gold。

## 6. 关于“文字准确率 95%”的判定

本次不能给出当前样本的真实 OCR 字符准确率。

原因：当前样本缺少人工确认的 `printed_questions_gold.json`。如果拿错误 gold 评估，会得到接近 0% 的假结果，这个数字没有意义。

有效验收口径应该是：

1. 先为当前样本建立人工 gold，覆盖 Q1–Q18。
2. 每题 gold 字段至少包含：
   - `question_number`
   - `printed_question_text`
3. 再用字符级 Levenshtein 评估：
   - 去空白
   - 默认忽略标点
   - 单题 ≥ 95% 算通过
   - 全卷 overall ≥ 95% 且无缺题，才算通过

当前系统还没有达到这个条件，因为当前样本没有人工 gold。结构层面修复后已达到 Q1–Q18 连续无重复，但文字是否 ≥95% 还不能证明。

## 7. 需要修复的问题

优先级从高到低：

1. 建立当前样本人工 gold
   - 当前结构已达 Q1–Q18 连续无重复。
   - 下一步必须补 `printed_questions_gold.json`，否则不能给真实 OCR 准确率。

2. 降低 layout 耗时波动
   - 修复后结构通过，但本轮 totalElapsedMs 增至 121.639 s。
   - 主要慢在 layout 阶段和 1 次 fallback。
   - 后续要优化为单页失败重试，不要拖慢全卷。

3. 继续抽查题干文字
   - Q3 合并后仍有 `[无法辨认]`，置信度 0.5。
   - Q14 跨页合并后文本较长，需要人工 gold 判定是否完整。
   - 不能用模型置信度或上一轮输出替代准确率。

4. 摆正后轻微倾斜复核
   - 几何预处理总体有效，但部分页面残余倾斜接近 2°。
   - 如果后续版面检测对倾斜敏感，需要加入二次 deskew。
